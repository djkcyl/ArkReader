# ArkReader 1.1.2

这一版主要减小程序体积，播放功能和界面保持不变。

- 桌面端改用按需编译的精简 FFmpeg，与 Android 共用构建配置。Windows 媒体组件从约 100.5 MiB 降至 3.3 MiB。
- 移除 macOS 的专用 H.264 转码。USM 影片统一保留 VP9 视频画面，转换音轨并重新封装；原始 MP4 直接使用。
- 合并重复的第三方许可正文，保留全部依赖署名和许可内容。

保留原有 O3 与 Thin LTO 编译配置。安装包和免安装包均包含所需媒体组件，更新后继续使用原来的资料库、收藏与阅读记录。

Windows、macOS Apple Silicon、Linux 与 Android 同步发行。下载校验值见 `SHA256SUMS.txt`。macOS 应用尚未公证；部分 Windows 环境下偶发的 WebView2 启动异常仍在排查。
