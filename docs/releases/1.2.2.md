- 支持分享剧情链接。在播放器设置的「播放控制」中复制链接，对方打开后即可在网页版观看对应剧情。
- 客户端下载并入应用导航页签，切换时不再离开当前页面。网页版首次打开默认进入主题曲。
- 改善手机横屏播放：进入剧情时尝试全屏和横屏，浏览器不支持时自动调整播放区域。修正旋转后弹窗、滑块和触摸操作的位置。
- 手机竖屏下主页音乐选择铺满页面，横屏采用分栏布局；改善平板目录与音乐面板的显示。
- 全屏进度条按需显示，触摸唤出时不会推进剧情，操作结束后自动收起。
- 修复音乐面板关闭图标重叠、自定义光标随窗口变大变小，以及滚动条上切回系统光标的问题。手动滚动脚本时会停止跟随播放。
- 修复「揭幕者们」活动片头等影片因音轨结束标记而封装失败的问题。
- 改善旧版 WebView 的音乐面板与滚动条兼容性，避免缺少弹出层支持时出现界面异常。

Windows、macOS、Linux、Android 和 Web 统一发行。网页版由发布流程自动更新。
