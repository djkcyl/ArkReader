ArkReader 1.0。

### 下载

| 系统          | 架构          | 安装包                  | 免安装包                   |
| ------------- | ------------- | ----------------------- | -------------------------- |
| Windows 10/11 | x64           | `windows-x64-setup.exe` | `windows-x64-portable.zip` |
| macOS 12+     | Apple Silicon | 对应架构 `.dmg`         | 对应架构 `-app.zip`        |
| Linux         | x64           | `.deb`                  | `.AppImage`                |
| Android 7+    | ARM64         | `.apk`                  | —                          |

文件名均以 `ArkReader-1.0.0-` 开头。`SHA256SUMS.txt` 提供全部文件的 SHA-256。
macOS 包采用 ad-hoc 签名，尚未做 Apple Developer 公证；首次运行可能需要在系统设置中允许打开。
Linux 构建基于 Ubuntu 22.04，安装包需要 WebKitGTK 4.1；AppImage 内含所需媒体框架。

### 功能

- 官方剧情目录、干员筛选、收藏、最高阅读进度与续播。
- 官方风格的剧情播放、回顾、倍速、阅读模式、窗口与系统全屏。
- 启动阶段准备 UI、封面和所选主页音乐；常用资源跨启动复用。
- 单段与批量缓存、并发下载、总进度和下载速度。
- 每次启动检查官方版本，播放前检测尚未适配的指令和参数。

### 数据与升级

安装版和免安装版共用系统用户目录，不把资源包、设置或阅读记录写入程序目录。

- Windows：`%APPDATA%\io.arkreader.desktop\library`
- macOS：`~/Library/Application Support/io.arkreader.desktop/library`
- Linux：`${XDG_DATA_HOME:-~/.local/share}/io.arkreader.desktop/library`

发行包不含个人数据、游戏原始包、游戏图片/音频或开发环境。首次运行从官方来源准备资源。
iOS 暂不提供。

### 验证范围

桌面与 Android 共用 Rust 资源引擎，不含 Python 运行时。

三个桌面平台通过构建与启动检查。Windows 原生窗口和独立 Android 15 模拟器完成了代表性剧情、缓存、续播、触控、音效及影片回归；不代表全部剧情、分支或全部机型覆盖。
