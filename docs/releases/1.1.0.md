ArkReader 1.1.0 带来更方便的剧情回顾、脚本查看和音量控制，并改进原版风格界面与资源缓存。

### 新增

- **同步脚本查看器**：在播放器底部逐行查看可读脚本或原文，自动跟随播放；点击脚本行即可跳转，拖动选字不会误跳。
- **回顾跳转与快捷快进**：点击 LOG 中的对白回到对应位置，桌面按住 Ctrl 可临时以 32 倍速快进。
- **独立音量控制**：分别调整界面音效、主页音乐和剧情播放器的音量。
- **阅读记录管理**：支持删除单条历史及其观看进度；收藏、缓存和清理操作增加确认弹窗。

### 优化与修复

- 应用按钮、开关、滑块和选择控件采用原版资源，修正宽窗口内容过窄、页签尺寸不一致及窄窗口排版问题。
- 改善 LOG 高亮范围与姓名排版；历史预览根据保存的进度显示对应人名和台词。
- 资源更新复用未变化的已下载文件，启动时清理不再使用的资源缓存。
- 修复 DT-1 开场字幕落在明暗交界处，以及黑幕合拢时出现细线的问题。
- 修正 Android 启动图标，触屏操作不再显示鼠标光标。

### 下载与升级

提供 Windows x64 安装器和便携 ZIP、macOS Apple Silicon DMG 和应用 ZIP、Linux x64 DEB 和 AppImage，以及 Android ARM64 APK。`SHA256SUMS.txt` 包含全部发行文件的校验值。

安装版直接更新；便携版解压到新目录后运行。资料库、收藏、设置和阅读记录保存在系统用户目录中，会继续保留。资源目录调整后，首次启动可能需要重新准备部分缓存。Android 可覆盖安装，保留应用数据。

### 已知问题

- Windows 部分环境下曾观察到 WebView2 启动异常，重新打开可恢复，原因仍在排查。
- macOS 应用尚未公证，首次打开可能需要在系统设置中允许运行。
