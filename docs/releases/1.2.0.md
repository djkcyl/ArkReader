## 网页版

- 新增纯静态网页版，可部署到腾讯云 Makers 等静态托管服务，无需后端。
- 浏览器内完成资源下载、解析、缓存与影片处理，支持手机布局、触屏长按和返回操作。
- 保留剧情播放、脚本查看与跳转、收藏、历史记录、单段和批量缓存及离线阅读。
- Web ZIP 解压后即可部署；从源码部署可使用 `npm run web:build:hosted`，输出目录为 `web-dist`。
- Makers 等托管平台可监听 `web` 分支自动部署，安装命令为 `npm ci`，构建命令为 `npm run build`，输出目录为 `dist`；不需要在托管平台安装 Rust。

## 资源

- 桌面和 Android 新增 PRTS 来源选择；网页版使用 PRTS。
- 全平台统一使用 Android 剧情资源，相同文件校验通过后直接复用。
- 网页版的内置 UI 和字体读取 PRTS 客户端归档；原生应用仍读取官方 Android APK 中的所需文件。
- 影片组件按实际格式裁剪，移除网页版通用 FFmpeg 包。
- 慢速下载持续接收数据时不再因固定总时限而中断；版本检查不使用浏览器的旧 HTTP 缓存。

安装版、免安装版、APK 和 Web ZIP 均在本页下载，校验值见 `SHA256SUMS.txt`。更新原生应用会保留资料库和阅读记录；网页版数据保存在当前浏览器中。
